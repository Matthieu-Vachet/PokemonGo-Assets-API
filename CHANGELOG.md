## 1.0.0 - 2026-08-13

### Added

- Établit la première version explicite du dépôt d’assets sans modifier les fichiers binaires publiés.
- Sépare la version de release SemVer de `assetVersion`, qui évolue lorsqu’un asset canonique est ajouté, retiré ou remplacé.
- Ajoute un contrôle CI qui exige une version et un changelog pour les changements d’assets, sans bloquer la documentation, les tests ou la CI seuls.
